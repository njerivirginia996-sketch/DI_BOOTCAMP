# Daily Challenge: Generic React List

A TypeScript + React book library that demonstrates a reusable `List<T>` component, a typed `Book` model, and `useState` updates for adding and removing books. Search and genre filters use the same typed book collection.

## Run locally

```powershell
npm install
npm run dev
```

## Validate

```powershell
npm run build
npm run lint
```

The generic list implementation is in `src/components/List.tsx`; the book model and application state are in `src/BookApp.tsx`.
