# Exercise XP Gold

Advanced TypeScript: Using TypeScript with React. Each exercise is an independent Vite + React + TypeScript project.

## Exercise 1: Form Management Hook

```powershell
cd Exercise-1-Form-Hook
npm install
npm run dev
```

## Exercise 2: Generic Data Table

```powershell
cd Exercise-2-Generic-Data-Table
npm install
npm run dev
```

## Exercise 3: Data Fetching and Cache

```powershell
cd Exercise-3-Data-Fetching-Cache
npm install
npm run dev
```

Each project also provides `npm run build` and `npm run lint`.
