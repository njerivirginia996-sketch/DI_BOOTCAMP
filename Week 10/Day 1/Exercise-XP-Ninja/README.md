# Exercise XP Ninja

Each exercise is an independent React + TypeScript + Vite project with its own `package.json`, `src`, `tsconfig.json`, and `vite.config.ts`.

| Exercise | Project folder |
| --- | --- |
| 1. Profile reducer | `Exercise-1-Profile-Reducer` |
| 2. Survey feedback | `Exercise-2-Survey-Feedback` |
| 3. Contact form reducer | `Exercise-3-Contact-Form` |
| 4. Shared contacts with context | `Exercise-4-Contact-Context` |
| 5. Focus input with `useRef` | `Exercise-5-Use-Ref` |

Run any exercise separately, for example:

```gitbash
cd Exercise-1-Profile-Reducer
npm install
npm run dev
```

Each project has its own `npm run build` command.
