# Atmos Weather App

A responsive React weather app with city search, current conditions, a five-day forecast, and locally saved favorite cities.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with `npm run build` and check the project with `npm run lint`.

Weather and geocoding data are provided by [Open-Meteo](https://open-meteo.com/); no API key is required. Favorites are stored in the browser's local storage.
